# Portfolio

The home page is a small 3D park at golden hour. You start on a soccer field and walk to:

- **MacBook**: my work, one project per Enter press
- **Monitor**: my experience
- **PSP**: playlists, favorites and (soon) a little game
- **Camera**: photos, viewed through the viewfinder
- **Shooting challenge** and **3-point shootout**: 60-second mini-games with best scores

Streams, a waterfall, a zen garden and a red bridge fill out the park. Signs float over every spot, a signpost at the start points the way, and **M** opens a map you can click to hop anywhere.

GitHub, LinkedIn, email and résumé links stay pinned on screen, and the regular site lives at `/classic`.

Content lives in `src/data/portfolio.ts`; drop a résumé at `public/resume.pdf`.

## Tech Stack

- **Astro** - Static site generator
- **Svelte** - UI framework
- **React Three Fiber + Rapier** - 3D world and physics
- **Three.js** - 3D graphics
- **GSAP** - Animations
- **Vercel** - Hosting
