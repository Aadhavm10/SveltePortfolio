# Portfolio

The home page is a small 3D world: dribble a soccer ball around to explore projects, read about me, and score goals to get in touch. The regular site lives at `/classic`.

## Tech Stack

- **Astro** - Static site generator
- **Svelte** - UI framework
- **React Three Fiber + Rapier** - 3D world and physics
- **Three.js** - 3D graphics
- **GSAP** - Animations
- **Vercel** - Hosting
